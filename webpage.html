API Workbench

Send a request to an API, add an optional key and JSON data, and inspect the response right here.

Request

Enter the endpoint and any data the API expects.

Sent as an Authorization: Bearer header. The key is not saved by this page.

The request will be sent as JSON. GET requests do not include a body.

Advanced: additional headers

Example: {"X-Client-Name": "my-app"}. These are added to the request.

Key safety: masking only hides the key on screen. A key used in a browser is still accessible to the browser user and may appear in developer tools. For a truly secret key, send requests through a secure server-side proxy you control.
